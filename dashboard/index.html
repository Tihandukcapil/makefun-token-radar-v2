LAUNCH RADAR

Every protocol that records no token, ranked by what its launch would be worth.

How a row is priced

implied value = size curve × sector × growth × age

The size curve is a least-squares fit of log market cap on log TVL over the protocols that already trade — a big protocol is not worth the flat multiple of a small one, because market cap grows slower than TVL. Sector is a fitted shift per category with at least five live protocols. Growth is the protocol's own seven-day TVL change, capped at ±20% a week, and age is how long it has run with no token; both enter at half their fitted weight, because the fit is strong in-sample but the two barely move the held-out miss, so the board does not let a hot week decide a rank. No protocol name is ever special-cased — the same function scores every row.

Market cap on TVL — the size curve, and where the board sits

Grey: the tokens that trade. Blue: this board's rows. Line: the size curve. A row's range is the full model's leave-one-out 25th–75th percentile — the board prints how often that range held.

An implied value is this radar's own claim, never a promise: it says what a token would be worth if the protocol's record stayed as it is. It does not predict whether or when a token is issued. A protocol is shown as recording no token when its DefiLlama record carries none — the record is not proof, and it may still hold one.
